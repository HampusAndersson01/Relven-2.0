## Legacy database audit (19 October 2026)

The original Relven phone source defines a Room database named `relven-workouts.db`. Its checked schema reaches version 18 and has 15 tables. Relevant durable content includes `cached_workout.documentJson` (keyed by server origin, owner, workout ID and revision), `cached_plan.documentJson`, `activity_outbox.documentJson`, `cached_activity.activityJson`, active workout snapshots, plan edits and schedule move/skip outboxes. This is a separate data model from RunnerUp's `runnerup.db`; a filename rename or table copy would corrupt semantics. Historical published database versions and actual user data still need verification.

A safe upgrade must preserve the old database untouched, read it without starting old sync workers, retain owner and revision identity, convert only document versions supported by the new importers, and report unsupported records separately. Activity history requires its own mapping and duplicate policy. The current v3 running-workout importer can process only a subset of old workout documents, so it is not yet a complete migration. Before any Play update, test against a copied old installation with the actual signing key and offer a user-controlled backup/export path.
