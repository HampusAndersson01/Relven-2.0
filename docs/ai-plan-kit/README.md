# Relven AI Plan Kit v1

This ZIP helps an external AI assistant produce a local Relven running plan. Relven does not call an AI service, require an account, or send plan content to one. Share this ZIP with the assistant you choose, then import its JSON result from **Workouts → Training plans → Import plan**.

The importable format is `relven.plan` schema version 1. Only scheduled running workouts and rest days are supported. Strength workouts, completed activity records, and plan ZIP imports are not supported. The included schemas and example come directly from the Relven source repository. Follow INSTRUCTIONS.md and validate the final JSON against both schemas.
